# 游戏内程序化角色生成与捏脸系统

## 项目描述

游戏内程序化角色生成与捏脸系统的bug修复项目。核心模块 `character/generator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 角色生成完全没做角色都是预设的
- 捏脸完全没做只能改几个参数
- 面部特征完全没做不能精细调整面部
- 体型参数完全没做只能改身高体重
- 角色预设完全没做不能保存和加载角色

## 运行测试

```bash
python -m pytest tests/test_character_generator.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
